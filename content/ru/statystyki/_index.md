Цифры ниже собраны из **рассказов людей, ведущих дела**, а не из официальной статистики
ведомств. Каждая строка — одно дело: дата подачи заявления, дата решения, орган, вид дела.

Данные анонимны — мы не собираем имён, номеров дел и контактов.
Хотите добавить своё дело? Напишите нам или отправьте pull request с новой строкой
в файле `assets/data/sprawy.csv`.
